DB First Approach with Entity Framework Core

Reusable setup guide for ASP.NET Core MVC with SQL Server

STEP 1

Install SQL Server Management Studio (SSMS)

Link: https://learn.microsoft.com/en-us/ssms/install/install

STEP 2

Install SQL Server Express

Link: https://www.microsoft.com/en-us/sql-server/sql-server-downloads

STEP 3

Create the SQL Server Database and Table

Open SSMS, connect to your SQL Server Express instance, open a new query window, and execute the following script.

CREATE DATABASE HospitalManagementSoftwareDb;
GO

USE HospitalManagementSoftwareDb;
GO

CREATE TABLE Patients
(
    -- Primary Key
    PatientId INT IDENTITY(1,1)
        CONSTRAINT PK_Patients PRIMARY KEY,

    -- Patient Information
    FirstName NVARCHAR(100) NOT NULL,
    LastName NVARCHAR(100) NOT NULL,
    DateOfBirth DATE NOT NULL,
    Gender NVARCHAR(20) NOT NULL,

    -- Record Creation Date
    CreatedAt DATETIME2(0) NOT NULL
        CONSTRAINT DF_Patients_CreatedAt
        DEFAULT (SYSUTCDATETIME()),

    -- Gender Validation
    CONSTRAINT CK_Patients_Gender
        CHECK (Gender IN ('Male', 'Female', 'Other')),

    -- Date of Birth Validation
    CONSTRAINT CK_Patients_DateOfBirth
        CHECK (DateOfBirth <= CAST(SYSUTCDATETIME() AS DATE))
);
GO

STEP 4

Create a New ASP.NET Core MVC Project

  1. Open Visual Studio.
  2. Select Create a new project.
  3. Select ASP.NET Core Web App (Model-View-Controller).
  4. Enter your project name.
  5. Select the required .NET version.
  6. Create the project.
STEP 5

Install Required EF Core Packages

Open: Tools → NuGet Package Manager → Manage NuGet Packages for Solution

  1. Microsoft.EntityFrameworkCore
  2. Microsoft.EntityFrameworkCore.SqlServer
  3. Microsoft.EntityFrameworkCore.Tools
  4. Microsoft.EntityFrameworkCore.Design
STEP 6

Scaffold the Database

Open: Tools → NuGet Package Manager → Package Manager Console

First time scaffolding

Scaffold-DbContext "Server=.\SQLEXPRESS;Database=HospitalManagementSoftwareDb;Trusted_Connection=True;TrustServerCertificate=True;" Microsoft.EntityFrameworkCore.SqlServer -OutputDir Models -ContextDir Data -Context HospitalManagementSoftwareDbContext -NoOnConfiguring -DataAnnotations

Scaffolding again after database changes

Scaffold-DbContext "Server=.\SQLEXPRESS;Database=HospitalManagementSoftwareDb;Trusted_Connection=True;TrustServerCertificate=True;" Microsoft.EntityFrameworkCore.SqlServer -OutputDir Models -ContextDir Data -Context HospitalManagementSoftwareDbContext -NoOnConfiguring -DataAnnotations -Force

STEP 7

Add the Connection String

Open appsettings.json and add the connection string inside the root JSON object.

{
  "Logging": {
    "LogLevel": {
      "Default": "Information",
      "Microsoft.AspNetCore": "Warning"
    }
  },
  "ConnectionStrings": {
    "HospitalManagementSoftwareDb": "Server=.\\SQLEXPRESS;Database=HospitalManagementSoftwareDb;Trusted_Connection=True;TrustServerCertificate=True;"
  },
  "AllowedHosts": "*"
}
The connection string name is HospitalManagementSoftwareDb. This exact name will be used in Program.cs.
STEP 8

Register the DbContext in Program.cs

First, make sure these namespaces are available:

using Microsoft.EntityFrameworkCore;
using YourProjectName.Data;

Then register your DbContext in Program.cs:

builder.Services.AddControllersWithViews();
builder.Services.AddDbContext<HospitalManagementSoftwareDbContext>(options => options.UseSqlServer(builder.Configuration.GetConnectionString("HospitalManagementSoftwareDb")));
STEP 9

Create Patients Controller

Controller Location

Controllers
    └── PatientsController.cs

PatientsController.cs

using Microsoft.AspNetCore.Mvc;
using Microsoft.EntityFrameworkCore;
using HospitalManagementSoftware.Data;

namespace HospitalManagementSoftware.Controllers;

public class PatientsController : Controller
{
    private readonly HospitalManagementSoftwareDbContext _context;

    public PatientsController(HospitalManagementSoftwareDbContext context)
    {
        _context = context;
    }

    public async Task<IActionResult> Index()
    {
        var patients = await _context.Patients.ToListAsync();
        return View(patients);
    }
}

STEP 15

Display Patient Data in the View

Use a foreach loop to display each patient record.

@model IEnumerable<HospitalManagementSoftware.Models.Patient>

@{
    ViewData["Title"] = "Patients";
}

<h1>Patients</h1>

<table class="table">
    <thead>
        <tr>
            <th>Patient ID</th>
            <th>First Name</th>
            <th>Last Name</th>
            <th>Date of Birth</th>
            <th>Gender</th>
            <th>Created At</th>
        </tr>
    </thead>

    <tbody>
        @foreach (var patient in Model)
        {
            <tr>
                <td>@patient.PatientId</td>
                <td>@patient.FirstName</td>
                <td>@patient.LastName</td>
                <td>@patient.DateOfBirth.ToString("dd/MM/yyyy")</td>
                <td>@patient.Gender</td>
                <td>@patient.CreatedAt</td>
            </tr>
        }
    </tbody>
</table>
